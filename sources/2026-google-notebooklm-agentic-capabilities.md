This Google Blog post announces the June 2026 upgrade to NotebookLM, introducing Gemini 3.5 with a secure cloud computer enabling code execution and over 100 curated software skills for deeper research analysis. The upgrade adds source discovery from open-ended questions via Google Search, allowing users to begin research without pre-loaded sources and build the source repository through the chat interface. New output formats — PDF reports with charts and tables, Excel spreadsheets, PowerPoint presentations, CSV, SVG, JSON, DOCX, and markdown — are available directly from the Studio panel. Google reports internal side-by-side evaluations against the prior system showing a 65%+ overall win rate across five core dimensions, with 69.9% on large document analysis and 78.2% on advanced web research and source discovery. These results are based on internal vendor evaluation and should be interpreted in the context of self-reported performance claims.
