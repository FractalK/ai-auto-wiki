OpenAI's April 2026 update to the Codex desktop application for macOS and Windows extends it from a coding assistant to a comprehensive software-development lifecycle platform. The update introduces background computer use — multiple agents can operate all desktop applications simultaneously via mouse and keyboard without interfering with the developer's active session — alongside an in-app browser for localhost and frontend development, image generation via gpt-image-1.5, and more than 90 new plugins including MCP servers for Atlassian Rovo, CircleCI, CodeRabbit, GitLab Issues, Microsoft Suite, and Neon/Databricks. Cross-session automations allow agents to schedule and wake themselves up to continue long-running tasks across days or weeks using preserved conversation context, and a new memory feature retains user preferences, corrections, and accumulated context across sessions. All capability claims are vendor-self-reported in a product launch announcement.
