The IBM Defense Model is a specialized large language model developed through a partnership between IBM and Janes that layers Granite foundation model architecture on Janes' curated open-source defense intelligence data covering equipment specifications, government statements, and field documentation across militaries worldwide. Unlike general-purpose models, it excludes internet training data to avoid the military information inaccuracies common in public sources, and instead queries continuously updated Janes data via secure scheduled feeds, enabling real-time intelligence updates without model retraining. IBM and Janes position the model as a decision-support tool for operational planning, intelligence functions, and defense industrial base strategy, deployable in air-gapped, classified, and edge environments via API integration. As of October 2025 the model was offered on a subscription basis but had not yet been publicly deployed at scale or independently benchmarked.
